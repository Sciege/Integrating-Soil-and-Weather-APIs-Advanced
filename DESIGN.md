# Design Direction: ITD112 Soil and Weather Integration Dashboard

Dial: ENERGY 2 / RHYTHM 2 / MOTION 1

## Visual Identity: Dark Tech Console
A focused, high-contrast meteorological and pedological operations console designed for precision data engineering. It replaces flat sterile backgrounds with a deep slate canvas (#0B0F12), elevated panel surfaces (#151C22), and luminous data indicators.

## Color System
- Canvas background: #0B0F12
- Elevated surface: #151C22
- Component border: #27333F
- Primary text: #F1F5F9 (17.5:1 contrast on #0B0F12, passes WCAG AAA)
- Secondary label text: #94A3B8 (6.7:1 contrast on #151C22, passes WCAG AA)
- Accent emerald/teal: #14B8A6 (6.9:1 contrast on #151C22, passes WCAG AA)
- Rainfall sky: #38BDF8 (8.0:1 contrast, passes WCAG AA)
- Deficit indicator: #7DD3FC
- Evapotranspiration line: #FBBF24 (10.3:1 contrast, passes WCAG AA)
- Soil clay: #FB923C (7.6:1 contrast, passes WCAG AA)
- Soil sand: #FDE047
- Soil silt: #4ADE80
- Map styling: carto-darkmatter

## Layout & Rhythm (RHYTHM 2)
- Compact top parameter toolbar with dark inputs and high-contrast primary button.
- Clean telemetry strip showing HTTP transport metrics (status, cache, payload).
- Paired 2-column comparative layout for balanced analytical viewing.
- Full-width dark cartographic map for Mindanao site locations.

## Motion (MOTION 1)
- Static, crisp data visualizations with dark-themed hover inspection tooltips.
- Zero gratuitous decorative animations.
